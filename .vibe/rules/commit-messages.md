# Commit messages

- **Language: English only** — use English for all commit messages, even when the plan or docs are in French.
- Conventional Commits: `type(scope): summary`
- Types: feat, fix, chore, refactor, test, docs
- Subject line: lowercase, imperative, no period, max 72 chars
- Blank line between subject and body

# Body structure

- Bullet list with `- Feature name:` followed by a concise description
- Wrap lines at 72 characters; indent continuation lines with 2 spaces
- Focus on what and why, not how

# New workspaces or modules section

- When the change adds whole new files or a new workspace, end with a
  `New modules:` section

# DCO (Developer Certificate of Origin, enforced in CI)

- Every commit ends with the `Signed-off-by:` trailer matching the committer
  identity (`git commit -s`). A commit without it fails the DCO check.

# Attribution trailer

- After the sign-off, add the Vibe attribution:

```
Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>
```
